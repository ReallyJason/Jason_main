# Social Media Platform

A simple social media platform built with PHP and MySQL.

## Features
- User Registration and Login
- User Profile with Bio and Profile Picture
- Posting updates
- Feed view of all posts
- Session management

## Setup
1. Create a MySQL database named `social_media`.
2. Import `database.sql` into the database.
3. Configure `db.php` with your database credentials.
4. Run the application on a PHP-enabled server.
